INSTALL
1. Fully close After Effects.
2. Double-click INSTALL_Ethan_Hub.bat.
3. Reopen After Effects.
4. Window > Extensions (Legacy) > Ethan's Editing Hub PREMIUM 2.0

IMPORTANT WORKFLOW
- Force Resolution is OFF by default.
- Split clips manually, then use SELECT ALL SPLIT CLIPS.
- Ethan's Viral Edit names: intro / beat drop / Split Clip#1, #2, etc.
- Edit Audio is created at the bottom: eye OFF, audio ON.
- Visual clips stay visible with audio OFF.
- No Color -> Color is added to every clip after intro using an adjustment layer whose opacity Easy-Eases 100% -> 0%.
- Motion Tile is applied to every selected visual clip as “Ethan's Best Motion Tile”.

KEYFRAME RULES
- Every Viral zoom is rebuilt so its animated preset properties cannot remain clumped.
- 2-key zoom: start + smooth tail.
- 3-key zoom: start + exact middle + smooth tail.
- Zoom tail extends 3 frames beyond the clip for a less rushed finish.
- Shift X / Shift Y keys are aligned to every Z Dist zoom key where those properties exist.
- Slide Down 1 / Slide Left 1 live at the outgoing clip END and finish 2 frames past it.
- Slide Down 2 / Slide Left 2 live at the incoming clip START.
- Slide rotation is neutralized to prevent accidental upside-down footage.
- Viral timing keys are Easy Eased, including Edge Rays, Ripple/Jaws preset keys, Halftone, blur, saturation, zooms and slides.
